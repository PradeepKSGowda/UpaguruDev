## Objective
Implement the automated Playwright End-to-End test suite covering the full Administrative Human-in-the-Loop (HITL) journey:
1. Protected route redirection and authentication guards (`/admin` -> `/auth/login?returnTo=/admin`)
2. Admin credential login and session verification (`/auth/login`)
3. Draft Review Queue inspection and filtering (`/admin/drafts`)
4. Side-by-side verification workspace comparing raw OCR extracted text against editable structured schema fields (`/admin/drafts/[id]`)
5. Human verification workflow, field modification, approval, and publication state assertion
6. Live reflection verification of newly approved notifications on Candidate Portal (`/`)
7. Draft rejection modal safeguards enforcing mandatory operator reasoning ($\ge 10$ characters)
Author the PostgreSQL telemetry migration `playwright-admin-telemetry-schema-v1.sql` with mandatory RLS and security definer logging procedure.
