## Objective
Implement PostgreSQL Generalized Inverted (GIN) indexing and full-text search (FTS) infrastructure for the UPA-GURU exam notification platform. This replaces unindexed, sequential-scan `ILIKE` queries with high-performance `tsvector` / `tsquery` full-text search, supporting weighted multi-attribute ranking across notification titles, reference numbers, conducting body names (e.g. UPSC, KPSC, SSC), and exam titles, along with dedicated performance telemetry and a high-throughput RPC function.
