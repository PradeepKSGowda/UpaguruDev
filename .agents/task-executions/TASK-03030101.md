## Objective
Build complete administrative CRUD management for the master `exams` entity. Operators can inspect all competitive examination series in a responsive, filterable table (`app/admin/exams/page.tsx`), search by title/body/slug, filter by category, monitor linked notification counts, create new examination records (`app/admin/exams/new/page.tsx`), edit existing series (`app/admin/exams/[id]/edit/page.tsx`), and delete unreferenced exams via Server Actions with strict foreign-key protection and audit logging in `public.audit_logs`.
