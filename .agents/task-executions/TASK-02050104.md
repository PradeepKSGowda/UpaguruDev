## Objective
Implement the native Next.js 15 App Router dynamic XML sitemap at `app/sitemap.ts` (`/sitemap.xml`) and search crawler directives at `app/robots.ts` (`/robots.txt`). The dynamic sitemap aggregates the portal homepage, all 8 official examination categories (`/category/[category]`), all 37 Indian states and Union Territories (`/state/[state]`), all published competitive examination entity hubs (`/exam/[slug]`), and individual published notification detail pages (`/notification/[slug]`) with accurate `lastModified` timestamps, change frequencies, and search priority weights. The `robots.txt` configuration provides crawl instructions, protects private zones (`/admin/*`, `/auth/*`, `/api/*`, `/search`), and references the canonical XML sitemap.
