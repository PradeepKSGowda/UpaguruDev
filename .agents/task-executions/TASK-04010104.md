## Objective
Implement distributed Redis deduplication locking via Upstash Redis (`lock:crawler:{portal}:{pdf_hash}`) with offline in-memory fallback, and configure an autonomous background cron scheduling engine using `APScheduler` (AsyncIOScheduler) to execute portal crawls according to Indian Standard Time (IST): KPSC at 06:00, UPSC at 07:00, SSC at 08:00, and RRB at 09:00. In addition, provision operational API endpoints (`POST /api/trigger/{portal_code}`, `GET /api/status`, `GET /api/jobs`) protected by Bearer token authentication.
