## Execution Notes
1. **Low-Latency Edge Security**: Unauthenticated or unauthorized attempts to access `/admin/*` are terminated at the edge before any React Server Components execute or database queries run.
2. **Session Refresh Synchrony**: Calling `updateSession` on every matched request ensures tokens approaching expiration are rotated and forwarded to both request headers (for RSC) and response headers (for the browser).
3. **Open-Redirect Hardening**: In addition to preserving `returnTo`, the middleware sanitizes destination URLs to reject protocol-relative paths (`//`).
