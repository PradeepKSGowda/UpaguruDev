## Objective
Implement the declarative Playwright-powered crawler module for the Karnataka Public Service Commission (kpsc.kar.nic.in) along with the streaming PDF download, SHA-256 deduplication hashing, and dual-engine text extraction (`pypdf` with `pdfplumber` fallback) pipeline. The crawler detects new exam notifications, skips duplicates to avoid redundant AI token spend, extracts clean text from PDFs, and records execution audit telemetry in `public.crawl_runs` and `public.pdf_documents`.
