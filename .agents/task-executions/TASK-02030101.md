## Objective
Implement and harden the server-side data access function `getNotificationBySlug()` in `lib/data/notifications.ts`. The function queries Supabase PostgreSQL for a published notification by its unique URL slug, performs an inner join with the `exams` master table, maps all eligibility, syllabus, vacancy, and conducting body fields into a strongly-typed `NotificationDetail` domain model, and returns `null` for non-existent or unverified slugs. Also implements `getRelatedNotifications()` and `getAllPublishedNotificationSlugs()` to support detail page related feeds and ISR `generateStaticParams()`.
