## Objective
Establish the foundational administrative layout shell for the UPA-GURU Human-In-The-Loop (HITL) Verification Portal at `app/admin/layout.tsx`. The layout enforces server-side Role-Based Access Control (RBAC) preventing unauthorized candidate or unauthenticated access, integrates a responsive collapsible sidebar (`AdminSidebar.tsx`) with real-time active route highlighting, and features a top administrative header (`AdminHeader.tsx`) with user profile identity, role badges (`Admin` / `Super Admin`), and a secure logout action redirecting to `/auth/login`.
