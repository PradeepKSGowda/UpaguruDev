## Objective
Define the standardized, strongly typed Pydantic V2 output schema (`NotificationExtractedData` and composite sub-models) serving as the contract for Google Gemini API Structured Outputs (`response_schema`). The schema enforces strict **Null Discipline** (omitting or marking missing fields as `null` without hallucination), models critical recruitment facets (vacancies, educational criteria, community age relaxations, fee schedules, selection phases, important dates, and corrigendum flags), and matches the `public.draft_notifications.parsed_json` data structure for admin review in EPIC-03.
