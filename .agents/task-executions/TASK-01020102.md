## Execution Notes
1. **Next.js 15 Async Cookies Handling**: In Next.js 15, `cookies()` is an asynchronous function. `createServerClient` in `lib/supabase/server.ts` is implemented as an async factory (`await cookies()`).
2. **RSC Cookie Limitation Guard**: Writing cookies (`cookieStore.set`) in pure React Server Components throws a framework error during rendering. This is caught and safely handled in `lib/supabase/server.ts` because session refresh is proactively handled by `updateSession` in Next.js Middleware.
3. **Security Defenses**: In `lib/supabase/middleware.ts`, `supabase.auth.getUser()` is called instead of `getSession()`, guaranteeing that revoked or tampered sessions are rejected at the edge.
