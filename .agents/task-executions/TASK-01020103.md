## Execution Notes
1. **Google OAuth PKCE Flow**: The login page triggers `signInWithOAuth` targeting `/auth/callback` with PKCE verifier cookies handled automatically by `@supabase/ssr`.
2. **Open Redirect Defenses**: In `/auth/callback/route.ts`, the `next` destination parameter is strictly validated using regex and prefix checking to block external schema URLs (`https://`) and protocol-relative domains (`//attacker.com`).
3. **Dual Recovery Modes**: `/auth/forgot-password/page.tsx` supports both standard password reset emails and passwordless one-time password (Magic Link) sign-in.
