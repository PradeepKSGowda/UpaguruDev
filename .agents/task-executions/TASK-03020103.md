## Objective
Build the side-by-side Human-In-The-Loop (HITL) Draft Review Workspace at `app/admin/drafts/[id]/page.tsx`. Operators can compare AI-extracted raw OCR/text source on the left panel (`RawTextPanel`) against structured form fields on the right panel (`ParsedFieldsForm`), edit extracted values with inline Zod validation, and execute Approve or Reject actions via Server Actions with audit logging in `public.audit_logs` and `public.draft_verification_sessions`.
