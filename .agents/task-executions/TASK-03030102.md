## Objective
Build administrative CRUD management for the core `notifications` entity outside the automated scraper pipeline. Operators can inspect all notifications in a filterable table (`app/admin/notifications/page.tsx`), filter by status (`published`, `under_review`, `draft`, `archived`) and search keywords, author new job notifications manually with parent exam selection (`app/admin/notifications/new/page.tsx`), update active postings (`app/admin/notifications/[id]/edit/page.tsx`), and delete or archive outdated notifications via Server Actions with audit logging in `public.audit_logs`.
