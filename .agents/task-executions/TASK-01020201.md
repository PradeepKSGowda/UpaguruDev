## Execution Notes
1. **Privilege Escalation Neutralization**: `raw_user_meta_data` is client-writable, but `raw_app_meta_data` is strictly read-only to clients. The `BEFORE INSERT` trigger intercepts user insertion and hard-binds `{ "role": "candidate" }` into `raw_app_meta_data`.
2. **Dual-Sync Mechanism**: `set_user_role` atomically updates both `auth.users.raw_app_meta_data` (for JWT claim generation) and `public.profiles.role` (for relational joins and RLS policies).
3. **Audit Trail**: Every administrative execution of `set_user_role` logs previous and new roles to `public.audit_logs`.
