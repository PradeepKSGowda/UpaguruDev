## Objective
Implement the server-side data access layer at `lib/data/drafts.ts` for querying AI-extracted draft notifications from `public.draft_notifications`. Supports status filtering (`pending_review`, `approved`, `rejected`, or `all`), search on source URLs, confidence score threshold filtering, pagination (`page`, `pageSize`), and default priority sorting by `extraction_confidence_score ASC` (lowest confidence items first for human attention). Also implements `getDraftNotificationById(id)` to retrieve complete draft records with `parsed_json` and `raw_extracted_text` for the side-by-side verification workflow.
