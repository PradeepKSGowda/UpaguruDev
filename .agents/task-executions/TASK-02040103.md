## Objective
Implement the server-side search results page at `app/search/page.tsx` and the underlying `searchNotifications()` data access layer in `lib/data/notifications.ts`. The page reads URL query parameters (`?q=...`), calls PostgreSQL full-text search with relevance ranking (`ts_rank_cd`), renders matching `NotificationCard` components, reports total counts, supports server-side pagination, and delivers three distinct UX states: empty search exploration, matching card grid, and zero-match recovery suggestions.
