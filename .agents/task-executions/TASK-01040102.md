## Objective
Implement a distributed sliding window rate limiter in `lib/rate-limit.ts` using `@upstash/ratelimit` configured for 60 requests per 60-second window per client IP. Apply this protection to public API endpoints (`/api/v1/search` and `/api/v1/notifications`), ensuring that throttled requests return RFC 7807 problem details with `429 Too Many Requests`, while authenticated administrative operators bypass limits.
